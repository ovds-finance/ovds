# Remediation Register

## Overview

This register tracks all security findings from ZAP scans and manual testing.

| Field | Description |
|-------|-------------|
| Finding ID | Unique identifier (e.g., ZAP-001, MANUAL-001) |
| Title | Clear description of the vulnerability |
| Severity | Critical / High / Medium / Low / Informational |
| Source | ZAP / Manual Test / Code Review /渗透测试 |
| Affected Component | URL, API endpoint, module, parameter |
| Status | Open / In Progress / Fixed / Risk Accepted / False Positive |
| Owner | Assigned developer/team |
| Target Date | Agreed remediation date |
| Retest Result | Not tested / Fixed / Partially fixed / Not fixed / Risk accepted / False positive |
