# Guide: OTP Verification for OVDS SaaS and Online MOR using TIN

This document outlines the standard procedure for performing One-Time Password (OTP) verification within Online Management of Obligations and Registration (MOR) or Online Vehicle Delivery System (OVDS) Software-as-a-Service (SaaS) platforms using a Taxpayer Identification Number (TIN) and a registered mobile phone number.

## 📌 Prerequisites
* **Valid TIN**: A registered Taxpayer Identification Number.
* **Registered Mobile Number**: The active phone number linked to the TIN database.
* **SaaS Portal Access**: Valid credentials or access link to the OVDS / Online MOR platform.

## 🔄 Step-by-Step OTP Authentication Flow

```
[ User Enters TIN ] ➔ [ System Validates TIN ] ➔ [ System Fetches Phone Number ]
                                                              │
[ Access Granted ] 🔑 [ User Submits OTP ] ⬅️ [ SMS Sent to Registered Phone ]
```

### 1. TIN Input & Validation
* Navigate to the **OVDS SaaS** or **Online MOR** portal login/verification page.
* Input your official **Taxpayer Identification Number (TIN)** into the designated field.
* Click **"Verify TIN"** or **"Proceed"**. The system will match the TIN against the central tax database.

### 2. OTP Generation
* Once the TIN is validated, the system masks and displays the linked phone number (e.g., `******1234`).
* Click **"Send OTP"** or **"Request Verification Code"**.
* A secure, time-sensitive 4 to 6-digit token is generated by the SaaS platform.

### 3. SMS Delivery
* The network routes the token to your **relevant phone number** via a secure SMS gateway.
* **Note:** The OTP is typically valid for 3 to 5 minutes. Do not share this code.

### 4. Code Submission & Authorization
* Enter the received OTP into the portal's verification box.
* Click **"Verify & Submit"**.
* Upon successful validation, the session authorizes access to your online MOR portal or vehicle delivery dashboard.

## 🛠️ Troubleshooting Common Issues

| Issue | Root Cause | Solution |
| :--- | :--- | :--- |
| **No SMS Received** | Network congestion or incorrect TIN linkage. | Wait 60 seconds and click "Resend OTP". Verify that your SIM card is active. |
| **Expired OTP Error** | Code entered after the validity window. | Request a new OTP and enter it immediately. |
| **Invalid TIN Error** | Database mismatch or typo. | Double-check the numbers. If unresolved, update your phone records at the local tax office. |
